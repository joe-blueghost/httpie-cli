# CLAUDE.md

This project uses Cate for issue tracking and agent orchestration.

- Issue tracker: Jira (`HTTPIE` project on `blueghostai.atlassian.net`)
- Workflow config: `.cate/workflows.json`
- Every code change should be tracked by an issue and merged via a pull request. Default branch: `main`.
- Branch naming: `task/ISSUE-{number}-{description}`
- Commit format: conventional commits
